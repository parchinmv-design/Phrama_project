# PharmaFlow

WPF-приложение на C#/.NET 8 для учебного проекта по теме фармацевтики.

## Что реализовано

- Локальная SQLite-база данных создаётся автоматически при первом запуске.
- Роли: гость, клиент, фармацевт, администратор.
- Вход с проверкой логина и роли.
- Каталог аптечных товаров.
- Поиск, фильтрация по категории и аптеке, сортировка по названию/цене/остатку.
- Карточка товара с описанием, формой выпуска, ценой, остатком и рецептурностью.
- Корзина и оформление заказа с проверкой остатков.
- Добавление, редактирование и удаление товаров для фармацевта и администратора.
- SQL-скрипт схемы БД и ERD-описание.

## Запуск

```powershell
dotnet run --project PharmaOrderApp/PharmaOrderApp.csproj
```

## Тестовые пользователи

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin` | `admin` |
| Фармацевт | `pharm` | `pharm` |
| Клиент | `client` | `client` |

Также есть вход как гость.

## Где база

SQLite-файл создаётся при запуске здесь:

```text
%LOCALAPPDATA%/PharmaOrderApp/pharma.db
```

## Материалы по БД

- `PharmaOrderApp/Database/schema.sql` - таблицы, первичные и внешние ключи.
- `PharmaOrderApp/Database/seed.sql` - стартовые данные.
- `PharmaOrderApp/Docs/ERD.md` - ERD в Mermaid и список покрытых процессов.

## Важно

Пароли сейчас хранятся открытым текстом, потому что это учебный локальный прототип. Для продакшена нужно добавить хэширование паролей, аудит действий и нормальную регистрацию клиентов.
